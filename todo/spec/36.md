# Spec: User Votes and Score (Task 36)

## Objective
Enable user-driven scoring via voting, implementing toggle logic and accurate score delta management.

## Tech Stack
- Backend: Express.js, MongoDB

## Commands
- Build: `npm run build`
- Test: `npm test`

## Project Structure
- `be/src/models/voteModel.js`: New collection/schema for tracking votes.
- `be/src/services/voteService.js`: Logic for vote updates.

## Code Style
- Atomic updates to `Item.score`.
- Idempotent voting logic (toggle).

## Testing Strategy
- Integration tests: Verify score updates, verify `userVote` state in response.

## Boundaries
- Always: Ensure atomicity in score updates.
- Ask first: Any change to voting rules (no karma).
- Never: Allow multiple votes for same direction without toggle.

## Success Criteria
- [ ] `Votes` collection implemented.
- [ ] Vote/Undo/Switch logic implemented.
- [ ] Controller returns `{ score, userVote }`.

## Open Questions
- None.
