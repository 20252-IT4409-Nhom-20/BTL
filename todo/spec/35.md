# Spec: Authorization, Edit/Delete Logic (Task 35)

## Objective
Enforce access control for content moderation and ensure data integrity via soft-deletes and edit windows.

## Tech Stack
- Backend: Express.js, MongoDB (Mongoose)

## Commands
- Build: `npm run build`
- Test: `npm test`

## Project Structure
- `be/src/middleware/authMiddleware.js`: Ownership/Admin checks.
- `be/src/services/storiesService.js`: Business logic for edit/delete.

## Code Style
- Consistent ownership checks: `(item.by === user.id || user.role === 'admin')`.
- Soft-delete: Set `deleted: true`, scrub fields.

## Testing Strategy
- Tests for unauthorized access (403 Forbidden).
- Tests for expired edit windows (400 Bad Request).
- Tests for soft-delete content scrubbing.

## Boundaries
- Always: Verify user session/token before edit/delete.
- Ask first: Modifying the "2-hour" edit window policy.
- Never: Allow unauthenticated users to edit/delete items.

## Success Criteria
- [ ] `editItem` and `deleteItem` service methods implemented.
- [ ] Access control middleware enforced on routes.
- [ ] 403 Forbidden on unauthorized action.
- [ ] Soft-delete implementation (flag, field scrubbing).
- [ ] Edit window (2 hours) enforced.
- [ ] Edit tracking (`editedBy`, `editedAt`) implemented.
