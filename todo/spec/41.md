# Spec: Global Error UI (Task 41)

## Objective
Improve user experience by handling runtime errors gracefully and ensuring responsive layout stability.

## Tech Stack
- Frontend: React

## Commands
- Build: `npm run build`
- Dev: `npm run dev`

## Project Structure
- `fe/src/components/ErrorBoundary.jsx`: Error Boundary component.

## Code Style
- Reusable components for fallbacks.
- Media queries for responsive design.

## Testing Strategy
- Manual testing of error states.
- Responsive design checks across breakpoints.

## Boundaries
- Always: Wrap high-level routes/components in ErrorBoundary.
- Never: Leave raw crash screens exposed to users.

## Success Criteria
- [ ] `ErrorBoundary` implemented and applied.
- [ ] Empty state UI implemented.
- [ ] Responsive design hardening (Mobile/Tablet/Desktop).
