# Spec: Story and Comment Creation (Task 34)

## Objective
Implement CRUD operations for creating stories and comments, including structural hierarchy updates. Transition from legacy numeric IDs to MongoDB ObjectId.

## Tech Stack
- Backend: Express.js, MongoDB (Mongoose)

## Commands
- Build: `npm run build`
- Test: `npm test`

## Project Structure
- `be/src/services/storiesService.js`: Logic for creation and hierarchy updates.
- `be/src/controller/storiesController.js`: Request/Response handling.

## Code Style
- Use `ObjectId` for `_id` field.
- Atomic updates: `$push` for comment children, `$inc` for root story `descendants` count.

## Testing Strategy
- Unit tests for service methods.
- Integration tests for `POST /stories` and `POST /comments`.
- Verify `descendants` count increments correctly.
- Verify `kids` array updates correctly.

## Boundaries
- Always: Use transactions if necessary for cross-document consistency (or ensure atomicity).
- Ask first: Major changes to the `Item` schema beyond `id` -> `_id`.
- Never: Implement custom sequential ID logic.

## Success Criteria
- [x] `createStory` and `createComment` implemented.
- [x] Schema updated to use `_id` (ObjectId).
- [x] Atomic updates for hierarchy (kids, descendants).
- [x] Returns 201 Created on success.
- [x] Returns 400 Bad Request on validation failure.
